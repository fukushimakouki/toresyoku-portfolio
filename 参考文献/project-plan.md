# 食事＆運動管理AI提案アプリ — プロジェクト計画

最終更新: 2026-09-03

## 1. 概要

- ユーザーが自身の情報（体重・身長・性別・目標・アレルギーなど）と「今日の状況」を入力すると、AIがその日の運動メニューと食事を提案するWebアプリ
- チーム: 4人（Java / HTML / JavaScript少し。Spring Bootでのチーム開発経験あり）
- イベント: チャレキャラ（Challecara）— 学生が半年かけてプロダクトを作り、最後にコンテストで競う育成型プログラム
- 現状: 構想段階。実装物なし

## 3. ターゲット

- メイン: 大学1〜2年生（ここに絞る）
- 後回し: 中年層、社会人
- 絞る理由: 「一人暮らしで自炊が苦手」「ジムに行かず自重トレ」など提案内容を具体化できる

## 4. MVP（スコープ）

### 残す
- ユーザー登録・プロフィール（体重・身長・性別・目標・アレルギー・運動環境）
- 日々の体重記録＋グラフ
- AIによる「今日の運動メニュー＆食事」提案
- 提案履歴の保存

### 後回し
- 献立の詳細レシピ生成
- カロリー計算の厳密化
- 食事の写真入力
- 通知・リマインド
- 外部食品DB連携

## 5. 技術スタック

- Spring Boot 3系 + Thymeleaf + MyBatis + MySQL（CampusTradeと同構成を流用）
- AI: Gemini API（キーは発行済み。モデルは `gemini-2.5-flash` 想定。`responseMimeType: "application/json"` でJSON固定応答）
- グラフ: Chart.js
- APIキー管理: `application.properties` で `gemini.api.key=${GEMINI_API_KEY}` として環境変数から読む。コード直書き・コミット禁止

## 6. AI提案の設計

### プロンプトに含める入力
- プロフィール: 体重・身長・性別・年齢・目標・アレルギー・運動環境（ジム／自宅）
- 今日の状況: 自由入力（例:「バイトで疲れている」「学食しかない」）
- （本番では）直近の体重推移、過去の提案と実施状況

### 返答フォーマット（JSON固定）
```json
{
  "training": [
    { "name": "...", "sets": "...", "note": "..." }
  ],
  "meal": {
    "breakfast": "...",
    "lunch": "...",
    "dinner": "..."
  },
  "comment": "..."
}
```

## 7. サーバ側機能一覧

### デモ用（土曜の最小構成）
- 入力受付: プロフィール＋今日の状況をフォームから受け取りバリデーション
- プロンプト生成: 入力値をテンプレートに埋め込んでGemini向け指示文を組み立て
- AI呼び出し: Gemini APIへリクエスト。タイムアウト・エラー処理
- 結果パース: JSON → Java DTO
- 画面受け渡し: DTOをThymeleafに渡す

### 本番用（12月に向けて追加）
- 認証・認可: ユーザー登録、ログイン、自分のデータのみ閲覧可（Spring Security）
- プロフィール管理: CRUD
- 体重記録: 日付ごとの記録・更新・期間指定取得
- BMI・基礎代謝・目標カロリー計算（プロンプトにも渡す）
- 提案履歴の保存と過去分閲覧
- 食事・運動の実施記録: 提案どおりやったかのチェック、達成率集計
- 提案の文脈強化: 体重推移・過去提案・実施状況をプロンプトに含める（優先度高。「使うほど賢くなる」差別化ポイント）
- 目標管理: 目標体重・期限・進捗率
- API利用制御: 1日あたり回数制限、レート制限
- キャッシュ: 同日同入力なら保存済みを返す
- ログ・エラー処理: 失敗記録、リトライ、フォールバック固定メニュー
- 外部連携（余裕があれば）: 食品カロリーDB、通知

### 想定テーブル（本番用）
- `user` / `profile` / `weight_log` / `suggestion` / `meal_log` / `training_log`

## 8. 土曜デモの実装計画

CampusTradeの雛形をコピーし、DB・ログイン・Securityを全て外す。

```
src/main/java/.../
  DemoController.java   # GET /（入力フォーム）, POST /suggest（結果表示）
  GeminiService.java    # RestTemplateでGemini APIを呼び、JSONを受け取る
  dto/SuggestionResponse.java 等
src/main/resources/templates/
  index.html            # 体重・身長・性別・目標・今日の状況のフォーム
  result.html           # 運動3つ・食事3食・コメントを表示
application.properties  # gemini.api.key=${GEMINI_API_KEY}
```

### デモ演出
- 「今日の状況」欄に発表中に打ち込み、提案が変わるのを見せる
- フォームに発表用プロフィールを初期値で入れておく
- API失敗に備え、事前生成した結果のスクショをスライドに必ず入れる

### 判断ライン
木曜夜までに「フォーム送信 → Geminiの結果が画面に出る」まで到達しなければ、金曜はスクショ版に切り替えてリハに集中する。
